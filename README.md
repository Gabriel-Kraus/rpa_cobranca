# RPA de Cobrança

Automação em Python para gestão e envio de cobranças, geração de boletos em PDF e notificações automáticas aos clientes.

## 🚀 Funcionalidades
- Leitura e gestão de banco de dados SQLite
- Geração automática de boletos em PDF
- Envio automatizado de e-mails de cobrança com anexos
- Interface gráfica para gerenciamento (GUI)

## 🛠️ Tecnologias Utilizadas
- Python
- SQLite
- Selenium / AutoIt
- SMTP (smtplib)
